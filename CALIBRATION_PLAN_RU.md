# План калибровки splash-экрана (размеры и расположение)

На ноутбуке в обычном браузере блоки отображаются не так, как нужно — ниже план, **в каком порядке** и **что именно** править в `styles.css`, чтобы всё встало на свои места.

---

## Шаг 0: Зафиксировать, что не так

Откройте сайт на ноутбуке в обычном размере окна и запишите (или запомните):

- **Расположение:** видео слишком слева/справа? Фото съехало? Текст наезжает на фото? Подсказка слишком высоко/низко?
- **Размеры:** видео или фото слишком большие/маленькие? Текст мелкий или крупный? Кнопка «Telegram» велика/мала?
- **Промежутки:** между видео и фото мало/много места? Отступ от краёв экрана большой/маленький?

Дальше подстраиваем под это.

---

## Шаг 1: Соотношение колонок (кто сколько места занимает)

**Где в `styles.css`:** блок `.splash-content`, свойство `grid-template-columns`.

**Сейчас:**  
`minmax(0, 1fr) minmax(0, 2fr) minmax(0, 1fr)`  
— левая колонка 1 часть, центральная (фото) 2 части, правая (текст) 1 часть.

**Что менять:**

| Задача | Новое значение |
|--------|-----------------|
| Сделать все три колонки одинаковыми | `1fr 1fr 1fr` |
| Фото ещё шире, текст уже | `1fr 2.5fr 0.75fr` или `1fr 3fr 1fr` |
| Видео уже, фото и текст шире | `0.75fr 2fr 1.25fr` |
| Текст шире, видео и фото уже | `1fr 1.5fr 1.5fr` |

Правите только эту строку, сохраняете, обновляете страницу (F5) и смотрите — блоки смещаются влево/вправо, занимают больше/меньше места по горизонтали.

---

## Шаг 2: Расстояния между блоками и от краёв

**Где:** тот же `.splash-content`.

- **`gap`** — расстояние между видео, фото и текстом.  
  Сейчас: `clamp(1rem, 3vw, 2.5rem)`.  
  Если на ноутбуке слишком тесно — увеличьте минимум: например `clamp(1.5rem, 4vw, 3rem)`.  
  Если слишком далеко — уменьшите максимум: например `clamp(0.75rem, 2vw, 1.5rem)`.

- **`padding`** — отступ всего контента от краёв экрана.  
  Сейчас: `clamp(1rem, 4vw, 3rem)`.  
  Мало воздуха по краям — увеличьте: например `clamp(1.5rem, 5vw, 4rem)`.  
  Слишком много пустого места — уменьшите: например `clamp(0.75rem, 3vw, 2rem)`.

После изменений снова F5 и проверка на ноутбуке.

---

## Шаг 3: Высота видео и фото

**Где:**  
- `.splash-video-container` — свойство `max-height`  
- `.splash-photo img` — свойство `max-height`

**Сейчас:** оба `70vh` (70% высоты окна).

**Что менять:**

| Задача | Что сделать |
|--------|-------------|
| Видео и фото меньше (больше видно текст и подсказку) | Поставить, например, `60vh` или `65vh` в обоих местах |
| Видео и фото больше (крупнее по центру) | Поставить `75vh` или `80vh` |
| Только видео меньше | Менять только `max-height` у `.splash-video-container` |
| Только фото меньше | Менять только `max-height` у `.splash-photo img` |

Сохранить, F5, проверить.

---

## Шаг 4: Размер текста и кнопки

**Где в `styles.css`:**

- **Текст описания:** `.splash-description p` → `font-size`.  
  Сейчас: `clamp(0.9rem, 1.15em, 1.25rem)`.  
  Мелко на ноутбуке — увеличьте: например `clamp(1rem, 1.2em, 1.4rem)`.  
  Крупно — уменьшите: например `clamp(0.85rem, 1em, 1.1rem)`.

- **Кнопка «Telegram»:** `.splash-description .splash-telegram-btn` → `padding` и при желании `font-size`.  
  Сейчас padding: `clamp(0.5rem, 1.5vh, 0.75rem) clamp(1rem, 3vw, 1.875rem)`.  
  Кнопку сделать крупнее — увеличьте числа: например `clamp(0.6rem, 2vh, 0.9rem) clamp(1.25rem, 4vw, 2.25rem)`.

- **Подсказка внизу:** `.splash-hint p` → `font-size`.  
  Сейчас: `clamp(0.8rem, 1vw + 0.5rem, 1rem)`.  
  Крупнее: например `clamp(0.9rem, 1vw + 0.6rem, 1.1rem)`.

После каждого изменения — сохранить и обновить страницу.

---

## Шаг 5: Положение подсказки внизу

**Где:** `.splash-hint` → `padding-bottom`.

**Сейчас:** `clamp(1rem, 5vh, 3rem)` — отступ снизу.

Подсказка слишком прижата к низу — увеличьте: например `clamp(1.5rem, 6vh, 4rem)`.  
Слишком высоко от низа — уменьшите: например `clamp(0.5rem, 3vh, 2rem)`.

---

## Шаг 6: Отдельные настройки для «ноутбука»

Если на большом мониторе всё ок, а именно на ноутбуке (например ширина 1280–1440px) — не так, можно добавить отдельный медиазапрос только для этого диапазона.

В конец блока со стилями splash (перед закрывающей `}` или перед следующим большим комментарием) добавьте:

```css
/* Только для типичного ноутбука (подстройте ширину под свой экран) */
@media (min-width: 1025px) and (max-width: 1440px) {
    .splash-content {
        gap: 2rem;           /* расстояние между блоками */
        padding: 2rem;       /* отступ от краёв */
    }
    .splash-video-container,
    .splash-photo img {
        max-height: 65vh;    /* высота видео и фото */
    }
    .splash-description p {
        font-size: 1.05rem;  /* размер текста */
    }
}
```

Ширину `1025px` и `1440px` можно поменять под разрешение вашего ноутбука (узнать: F12 → вкладка «Elements» / «Инструменты» → включить адаптивный режим и посмотреть ширину, или просто сузить окно браузера и подобрать границы).

---

## Порядок калибровки (кратко)

1. **Колонки** — `grid-template-columns` у `.splash-content` (кто сколько места занимает).
2. **Промежутки** — `gap` и `padding` у `.splash-content`.
3. **Высота видео и фото** — `max-height` у `.splash-video-container` и `.splash-photo img`.
4. **Текст и кнопка** — `font-size` и при необходимости `padding` у описания и кнопки.
5. **Подсказка** — `padding-bottom` у `.splash-hint`, при желании `font-size` у `.splash-hint p`.
6. При необходимости — отдельный `@media` для диапазона ширины ноутбука.

После каждого шага сохраняйте `styles.css` и обновляйте страницу в браузере (F5), чтобы сразу видеть результат и ставить всё на свои места.
