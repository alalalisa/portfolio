# План: подключить Bootstrap только для splash-экрана

Bootstrap на сайте — это в основном **сетка** (колонки и ряды) и **утилиты** (отступы, текст, кнопки). Нам нужна только сетка для первого экрана. Остальной сайт (вторая страница, canvas, модалка) не трогаем.

---

## Что мы будем использовать из Bootstrap (минимум)

- **Container** — ограничивает ширину контента по центру.
- **Row** — один ряд.
- **Col** — колонки внутри ряда. Классы вида `col-12 col-md-6 col-lg-4`:
  - `col-12` = на маленьком экране колонка на всю ширину (12 из 12).
  - `col-md-6` = на экране от 768px две колонки по 6.
  - `col-lg-4` = на экране от 992px три колонки по 4.

Никаких компонентов (карусели, навбары) мы не используем — только сетка.

---

## Шаг 0: Что не трогаем

- Вторая страница (canvas, иконки, доска) — без Bootstrap.
- Модальное окно, кнопка меню — без Bootstrap.
- Все ваши скрипты (`script.js`, `p5_3d_shapes.js`) — без изменений.
- ID элементов (`#splash-screen`, `#splash-video`, `#splash-photo-img` и т.д.) — сохраняем, чтобы JS работал.

---

## Шаг 1: Подключить Bootstrap по CDN

В `<head>` файла `index.html` **после** вашего `styles.css` добавить одну строку:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
```

Только CSS. JavaScript Bootstrap не обязателен для сетки.

(Опционально: если потом захотите использовать выпадающее меню или модалки Bootstrap — тогда подключим и их JS.)

---

## Шаг 2: Разметка splash в терминах Bootstrap

Сейчас у вас структура:

```
splash-screen
  └── splash-content
        ├── splash-video-container   (видео)
        ├── splash-photo            (фото)
        ├── splash-description      (текст + кнопка)
        └── splash-hint             (подсказка внизу)
```

С Bootstrap будет так:

- **splash-screen** — как есть (полный экран, фон), внутри него:
  - **container** (Bootstrap) или **container-fluid** (на всю ширину) + ваши классы `splash-content` для высоты/выравнивания.
  - Внутри **row** (один ряд для видео + фото + описание).
  - В ряду три **col**: видео, фото, описание.
  - Отдельно второй **row** для подсказки (hint) внизу по центру.

Классы колонок подбираем так:

- **Мобильный (телефон):** всё в столбик — каждая колонка `col-12` (видео, фото, описание, подсказка).
- **Планшет:** например видео + фото в ряд, описание ниже или сбоку — `col-md-6` и т.д.
- **Десктоп:** три колонки видео | фото | описание — например `col-lg-4` или `col-lg-3` / `col-lg-6` / `col-lg-3` (если середина шире).

Конкретно:

- Блок 1 (видео): `col-12 col-lg-4` — на мобильном на всю ширину, на большом экране 1/3.
- Блок 2 (фото): `col-12 col-lg-4` или `col-lg-5` — на большом экране центр чуть шире.
- Блок 3 (описание): `col-12 col-lg-4` или `col-lg-3`.
- Подсказка: отдельная строка, одна колонка `col-12` с классом выравнивания по центру (`text-center`).

Все ваши ID и классы (`splash-video-container`, `splash-photo`, `splash-description`, `splash-hint`) оставляем — к ним привязаны стили и JS.

---

## Шаг 3: Что правим в `styles.css`

- **Не удаляем** ваши правила для `.splash-screen`, `.splash-video`, `.splash-photo img`, `.splash-description p`, кнопки, цветов и т.д.
- **Убираем или упрощаем** только то, что теперь делает Bootstrap:
  - У `.splash-content` убрать `display: grid`, `grid-template-columns`, `grid-template-rows`, `gap` — раскладку задаёт Bootstrap (row + col).
  - Оставить в `.splash-content` высоту, выравнивание по вертикали, padding — по желанию.
- **Конфликты:** Bootstrap задаёт свои отступы у `.container`, `.row`, `.col-*`. Если что-то «поехало», перебиваем в своих классах (например `.splash-content .row { margin: 0; }` или точечно padding/gap).

То есть: Bootstrap отвечает за **раскладку** (кто где стоит), ваши стили — за **внешний вид** (размеры видео/фото, цвета, шрифты, кнопка).

---

## Шаг 4: Порядок работы (чтобы ничего не сломать)

1. Сохранить бэкап или закоммитить текущее состояние.
2. Добавить в `index.html` ссылку на Bootstrap CSS (шаг 1).
3. Заменить внутренность `splash-content` на структуру **container-fluid → row → col** (шаг 2), сохранив все `id` и нужные классы.
4. Обновить `styles.css`: убрать grid у `.splash-content`, подправить отступы/выравнивание при необходимости (шаг 3).
5. Проверить в браузере: мобильная ширина, планшет, десктоп; клик по экрану и переход на вторую страницу; открытие модалки — всё должно работать как раньше.

---

## Шаг 5: Что смотреть на сайте Bootstrap (если захочется)

- **Grid:** раздел "Grid" в документации — там про `container`, `row`, `col-*`, breakpoints (`sm`, `md`, `lg`, `xl`).
- **Breakpoints:** какие ширины соответствуют `md`, `lg` и т.д. — чтобы подобрать колонки под телефон/планшет/десктоп.

Больше для нашей задачи с их сайта не нужно.
