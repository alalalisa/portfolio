# Загрузка на Cloudinary с новым неймингом (107 проектов, несколько медиа в одном)

## Структура файлов

- **icons/** — 107 иконок для доски (по одной на проект). Имена: `1.png`, `36a.png`, `104.png` и т.д. Для проекта с несколькими медиа можно использовать одну иконку (например `36.png` или `36a.png`).
- **images/** — все медиа для карточек. Имена: `9a.jpg`, `9b.jpg`, `104a.jpg`, `104b.JPG`, `36a.png`, `36b.png` и т.д. Число = номер проекта, буква = порядок (25a, 25b, 25c).

## Формат portfolio_data.json после загрузки

В JSON — **одна запись на каждый медиафайл** (не на проект). Пример для проекта 36 с четырьмя медиа (36a, 36b, 36c, 36d):

```json
{ "id": "36a", "media": { "filename": "36a.png", "type": "image", "path": "https://res.cloudinary.com/ВАШ_КОНТЕЙНЕР/image/upload/images/36a", "thumbnail": "https://res.cloudinary.com/ВАШ_КОНТЕЙНЕР/image/upload/icons/36a" }, "title": "Название проекта", "description": "...", "additional": { "col_2": "Тег", ... } },
{ "id": "36b", "media": { "filename": "36b.png", "type": "image", "path": "https://.../images/36b", "thumbnail": "https://.../icons/36b" }, ... },
{ "id": "36c", "media": { ... } },
{ "id": "36d", "media": { ... } }
```

- **id** — строка `"25a"`, `"104b"` или число `25` (если один медиа в проекте). Число в id = номер проекта, буква = порядок показа в карточке (по алфавиту: 25a, 25b, 25c).
- **media.path** — полный URL медиа на Cloudinary (папка images).
- **media.thumbnail** — URL иконки на Cloudinary (папка icons). Для иконки на доске берётся thumbnail **первого** медиа проекта (по порядку a, b, c…).
- **title**, **description** — можно задать один раз для первого медиа проекта; в карточке показывается заголовок и описание проекта (от первого элемента).

Код группирует записи по числу из id (25a, 25b, 25c → проект 25), сортирует по букве и показывает одну иконку на проект, в карточке — все медиа по порядку с прокруткой.
