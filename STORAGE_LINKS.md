# Ссылки с хранилища — почему не грузятся фото/видео и что сделать

## 1. Первая страница (фото и видео)

Откройте файл **storage_links.json** в корне проекта. Вставьте туда **рабочие прямые ссылки**:

```json
{
  "splashPhoto": "https://ваша-ссылка-на-фото.jpg",
  "splashVideo": "https://ваша-ссылка-на-видео.mp4"
}
```

- **splashPhoto** — прямая ссылка на фото справа на первой странице (например с Cloudinary, Imgur или другого хранилища).
- **splashVideo** — прямая ссылка на видео первой страницы (должен открываться в браузере по URL).

Сайт сначала подставляет эти ссылки. Если поле пустое, используются запасные варианты из script.js (Cloudinary).

## 2. Иконки и медиа проектов (карточки)

В **portfolio_data.json** у каждого элемента есть объект `media`:

- **media.path** — полный URL изображения или видео (для модального окна).
- **media.thumbnail** — URL иконки на доске.

Если иконки и картинки в карточках не грузятся:

1. Проверьте в Cloudinary (Media Library), что файлы загружены и имена/папки совпадают с путями в JSON (например `Alisa/images/3a`, `Alisa/icons/3`).
2. Либо замените URL в **portfolio_data.json** на свои рабочие ссылки с любого хранилища (каждый элемент — свои `path` и `thumbnail`).

## Итого

| Что не работает | Где вставить свои ссылки |
|-----------------|--------------------------|
| Фото первой страницы | **storage_links.json** → `splashPhoto` |
| Видео первой страницы | **storage_links.json** → `splashVideo` |
| Иконки и медиа в карточках | **portfolio_data.json** → у каждого элемента поля `media.path` и `media.thumbnail` |
