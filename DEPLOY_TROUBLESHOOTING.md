# Почему сайт не обновляется после коммита

## 1. Кэш браузера (самая частая причина)

Даже если GitHub уже отдаёт новый сайт, браузер может показывать старую версию из кэша.

**Что сделать:**
- **Жёсткое обновление:** `Ctrl+Shift+R` (Windows/Linux) или `Cmd+Shift+R` (Mac).
- Либо откройте сайт в **режиме инкогнито** (Ctrl+Shift+N в Chrome).
- Либо откройте с параметром: `https://alalalisa.github.io/portfolio/?nocache=1`

## 2. Задержка публикации GitHub Pages

GitHub Pages не обновляется мгновенно. Обычно 1–2 минуты, иногда **5–15 минут** или дольше.

**Что сделать:**
- Подождать ещё 5–10 минут.
- Проверить статус: в репозитории **Settings → Pages** — вверху должно быть сообщение вроде «Your site is live at…» и время последней сборки (если есть).

## 3. Настройки GitHub Pages (частая причина «сайт не обновляется»)

Если указана не та **ветка** или не та **папка**, сайт будет старым или вообще не обновляться.

**Обязательно проверьте по шагам:**
1. Репозиторий на GitHub → **Settings** → в левом меню **Pages**.
2. **Build and deployment** → **Source:** должно быть **Deploy from a branch**.
3. **Branch:** в выпадающем списке должно быть выбрано именно **main** (а не gh-pages и не другая ветка). Если там gh-pages — сайт показывает старую версию, пока вы пушите в main.
4. **Folder:** должно быть **/ (root)** (а не /docs). Нажмите **Save**.
5. Подождите 2–3 минуты, откройте сайт в режиме инкогнито или с жёстким обновлением (Ctrl+Shift+R).

## 4. Убедиться, что коммит действительно в main

1. На GitHub откройте репозиторий.
2. Убедитесь, что выбрана ветка **main**.
3. Проверьте, что последний коммит («v2: group by project…») есть в списке коммитов и что в нём изменены `index.html`, `script.js`, `styles.css`.

## 5. Проверка без кэша

- Откройте: `https://alalalisa.github.io/portfolio/?t=123` (меняйте 123 при каждой проверке).
- В коде к CSS и JS добавлен `?v=2` — после деплоя браузер подгрузит новые файлы. Если позже снова будете видеть старое, можно увеличить версию (v=3 и т.д.).

---

**Кратко:** чаще всего помогает **жёсткое обновление (Ctrl+Shift+R)** или открытие в **режиме инкогнито**. Если не помогло — проверьте **Settings → Pages** (ветка `main`, папка root) и подождите ещё 5–10 минут.
